ESPN Cricinfo Design System (2021–2025)




In 2021, ESPN Cricinfo embarked on an ambitious journey: unifying its web and mobile platforms under a single scalable design system. As the platform prepared to expand beyond web into mobile apps, wearables, and dynamic in-app features, the need for a robust, modular, and future-proof design system became critical

I joined the project as a Senior Product Designer and eventually evolved into the Design System Lead / System Thinker, managing everything from component audits to token creation, documentation, and developer alignment. Over four years, this system grew into the backbone of ESPN Crickinfo’s product design — 200+ Figma files, 30–40 core components, 100+ variants — enabling multiple teams to ship features faster and more consistently than ever before.
